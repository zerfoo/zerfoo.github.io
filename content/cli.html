Zerfoo CLI

Official command-line tool

The Zerfoo CLI is part of the public Apache-2.0 Zerfoo ML framework. It runs on your computer and supports model download, local inference and serving. It is separate from the browser-based model designer.

Install with Homebrew

brew install zerfoo/tap/zerfoo
zerfoo version

The official Homebrew tap builds the CLI from its pinned public source release. Model weights are separate downloads. Available memory and hardware requirements depend on your chosen model.

Install with Go

go install github.com/zerfoo/zerfoo/cmd/zerfoo@v1.60.0
zerfoo version

Use the Go version required by the selected release. See the installation guide for GPU setup and build requirements.

Script local workflows

zerfoo --help
zerfoo list
zerfoo serve --help

Inspect command help before running a workload. Serving exposes an API on your own host; it does not turn zer.foo into a hosted inference endpoint. Follow the server guide and quickstart for runnable examples.
