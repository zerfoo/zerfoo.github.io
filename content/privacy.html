Zerfoo privacy information

Scope and operator

This page describes the current zer.foo website and hosted model designer, operated by Sire Run, Inc. Questions can be sent to david@zer.foo, or by mail to 584 Castro St Suite #4211, San Francisco, CA 94114, United States.

Website and third-party services

Cloudflare serves the website and design API and processes requests as part of operating those services. The site loads Google Fonts and Google Analytics. Analytics receives page-view events and fixed-category funnel events such as chat started, design generated, design failed and project downloaded. The funnel event implementation does not include message text, datasets or model objectives. See Google privacy information and Cloudflare privacy information for their processing policies.

Hosted design conversations

When you submit a chat message, the website sends the conversation history to the design API. The API sends the conversation and relevant design context to OpenRouter and its selected model provider, currently MiniMax. See OpenRouter privacy information; provider data-use and retention terms apply; local training does not make hosted chat private to your device. Do not submit secrets, raw datasets or sensitive personal information. A concrete missing-capability feature request can be submitted to a public GitHub issue tracker; the system is instructed to use generic technical requirements, so review the returned request and avoid disclosing private details.

Cookies and operational records

The hosted designer sets an HttpOnly, Secure session cookie with a 24-hour lifetime. It stores request counters associated with salted hashes of IP addresses and session tokens to enforce limits. These counters do not automatically reset on New design. The browser keeps conversation state in the current page; the current application does not maintain a server-side chat transcript database. Hosting logs, analytics systems and model providers may process or retain operational data under their own policies. No specific deletion or retention period for those systems is promised here.

Public MCP documentation server

Requests to zer.foo/mcp are processed by the website’s Cloudflare Worker. Documentation queries and document URLs are used to return public references. This endpoint does not forward requests to OpenRouter or a model provider and does not read files on your computer. Hosting infrastructure can process request metadata as described above.

Local compute and choices

Downloaded projects are trained and evaluated on hardware you choose. Local dataset files are not uploaded by the website's chat interface. Model downloads, coding agents and any services you configure locally are governed by your choices and those services' terms. You may use the public library, CLI and documentation without using hosted chat. Contact the maintainer about privacy requests; do not include credentials or an entire private conversation in an initial email.
