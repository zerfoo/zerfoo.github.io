Built with a purpose

More people should
be able to build AI.

I’m David Ndungu. This work began with Therfoo’s first commit on January 23, 2019: exploring neural networks, dense layers and backpropagation in Go. Zerfoo carries that work forward to build AI for real problems. Today, the goal is to make model creation and training accessible to anyone with an idea and their own hardware. Zerfoo is an open-source project of Sire Run, Inc., built alongside tools like Ajent for sharing what coding agents learn.
