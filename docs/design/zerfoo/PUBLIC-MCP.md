# Public documentation MCP

The canonical agent handoff begins at `https://zer.foo/llms.txt`, which links to
current agent guidance, public interfaces, local runtime setup and model evidence.
The website's initial instruction, copy action and reset use that entry point;
project downloads retain their project-specific AGENTS.md handoff and local Kazi
approval/execution boundaries.

`https://zer.foo/mcp` is a public Streamable HTTP endpoint using the official MCP
TypeScript server SDK. It serves the 2026-07-28 protocol and stateless legacy
initialization. It exposes `search_docs`, `read_document`, `get_local_workflow`,
three reference resources, and the `create_zerfoo_model` prompt.

This endpoint has no model-provider credential or inference call, no training
execution, and no access to the user's filesystem. Documentation reads are
restricted to a build-generated index of public assets. Inputs and POST bodies
are bounded; supplied foreign Origins are rejected. Browser preflight is allowed
only for the site's own origin. No sign-in is required for public references.

The server does not wrap the hosted designer or forward its IP/session identity.
That API retains its own quotas and potential feature-request effects. Local
creation/training remains on the installed runtime and Kazi interfaces; the MCP
endpoint neither schedules that work nor assumes authority to run it.

## Validation

- `npm test`: handoff consistency/reset, official modern MCP client, legacy
  initialization, resources, prompts, search/read pagination, input bounds,
  arbitrary-URL rejection and Origin checks, plus existing website tests.
- `node scripts/verify-mcp.mjs [origin]`: real MCP client discovery and calls,
  public resources, prompt retrieval, legacy compatibility and Origin rejection.
- `node scripts/verify-agent-endpoints.mjs [origin]`: HTML/Markdown and public
  machine-readable endpoints remain compatible.

The MCP index is generated by the existing site build. New docs deployments need
`npm run build` before deployment. The endpoint advertises public facts only;
documentation availability is not evidence of model/hardware qualification.
